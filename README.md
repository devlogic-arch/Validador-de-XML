🛠️ Ferramenta de Validação Fiscal
Ferramenta desenvolvida a partir de uma demanda prática para verificar se informações fiscais como cClassTrib, CST ICMS, CST PIS/COFINS e cálculos de ICMS/IBS/CBS estão corretos.

A aplicação utiliza uma planilha CSV com dados pré-definidos para situações específicas, tendo NCM e CFOP como principais identificadores para validar e cruzar as demais informações.

🚀 Tecnologias utilizadas
HTML – estrutura da aplicação

CSS – estilização e layout

JavaScript (JS) – lógica de validação e manipulação dos dados

🎯 Objetivo
Garantir maior confiabilidade nos cálculos fiscais e otimizar o processo de conferência de informações tributárias, reduzindo erros manuais e aumentando a produtividade.

📂 Como funciona
O usuário importa a planilha CSV com os dados.

A ferramenta cruza NCM e CFOP com as regras pré-definidas.

São exibidos os resultados indicando se as informações estão corretas ou se há inconsistências.

✨ Diferencial
Esse projeto foi vibe coded por mim, unindo prática e criatividade para resolver uma dor real do dia a dia. A ideia é que qualquer pessoa que trabalhe com conferência fiscal possa usar a ferramenta de forma simples e intuitiva.
